# DECISIONS — принятые решения (MVP)

Пользователь не участвует в выборе решений; всё ниже — выбор разработчика
в пользу «простого рабочего варианта».

## Архитектура

1. **SSE вместо WebSocket/Socket.IO.** Платформа запускает `next start`
   без возможности подключить кастомный HTTP-сервер, необходимый Socket.IO.
   SSE даёт тот же push-канал (server→client) на чистых route handlers
   Node.js. Действия клиента идут обычным POST. При разрыве SSE клиент
   автоматически переходит на поллинг каждые 1.5 с и возвращается на SSE.
2. **In-memory хранилище комнат** (Map в модуле `src/server/rooms.ts`).
   PostgreSQL/Drizzle в MVP не используется для игрового состояния —
   комнаты живут в процессе. После рестарта сервера комнаты исчезают
   (документировано). Токены игроков хранятся в localStorage клиента,
   переподключение работает в рамках жизни комнаты.
3. **Один серверный тик 200 мс** ведёт все таймеры, ботов, автоход лото
   и физику Чапаева (4 подшага по 50 мс). Клиентские таймеры только
   отрисовка.
4. **Полный снапшот состояния в каждый push.** Для компании до 8 игроков
   это дешевле и надёжнее диффов; приватный срез `you` считается
   персонально для каждого подключённого клиента.
5. **Код комнаты — 4 символа** (без 0/O/1/I). Ссылка: `/room/CODE`.

## Общие правила игр

6. **Стартовый игрок** в карточных/очередных играх — случайный (сервер).
7. **Ничья** разрешена: все победившие получают очки первого места;
   в командных играх победившая команда получает 5, проигравшая — 3.
8. **Слова в Шляпе:** список ~140 слов с явными «запрещёнными
   однокоренниками» + автоматическая проверка на включение корня
   (prefix ≥ 3 символа). Написание слова-ответа в чат находит сервер
   (проверка всех сообщений в раунде 0 и 2) и пропускает слово с штрафом
   команде. В раунде жестов чат объясняющей команды игнорируется.
9. **Перудо:** первая ставка — минимум 2 штуки. После разбора
   «Не верю» ход переходит к игроку после сомневавшегося.
10. **Лото:** 90 чисел, интервал 5 с (сервер). Авто-режим отмечает числа
    сервером. Ложная заявка = автосписывание следующего попавшего числа
    («пропуск»). Ручной режим — игрок сам отмечает.
11. **Пароль:** подсказка — одно слово; запрещено слово-ответ,
    совпадение 3+ символов по началу и повтор подсказки.
12. **Верю — не верю:** можно врать полностью (0 карт нужного ранга).
    При «Не верю» стопка открывается: лгун забирает стопку, правдуша —
    сомневавшийся. После вскрытия ранг сдвигается, ход — у следующего
    после сомневавшегося.
13. **Чапаев:** таблица 8×8, шашки r=0.42, трение 0.97/шаг, выбитие
    при скорости > 0.24 у края, иначе упругий отскок. Матч до 3 побед
    в раундах. При 3–8 игроках — однокруговая сетка (bye для нечётного).
14. **Боты** действуют на сервере (тик), с человеческими задержками;
    в «Бонжур» бот с 10% вероятностью жмёт не то.
15. **Уход ведущего:** права переходят ближайшему живому человеку;
    если человек-ведущий ушёл, а других людей нет — комната закрывается.
16. **Звук** — синтез через WebAudio (без внешних файлов), есть mute.
17. **PWA** — манифест + лёгкий service worker (кэш shell), иконка SVG.
18. **Бренд:** только нейтральное «Вечер за столом: 8 игр онлайн»;
    внутреннее имя в коде — TableNight Online. Ни чужих логотипов,
    музыкальных и видеоматериалов.
